# 07 Templates

Formal Project AROC documents no longer start from a hand-edited `.docx` template. The
template *is* the pipeline: copy an existing document folder under `00 Engineering/`
(e.g. `AROC-STD-0002 Engineering Standards/`), keep its `build.py`, replace the
`chapters/*.json` content, and update `DOC_NUMBER` / `DOC_TITLE` / `REVISION` at the top
of `build.py`. Full authoring rules are in
`00 Engineering/AROC-STD-0001 Project AROC Publishing Standard Rev0.2.docx` (Chapter 3).

The original Rev0.1 `.docx` templates (ChatGPT-era, navy/blue identity) are preserved for
history in `99 Archive/0003A-chatgpt-draft-rev0.1/`.
